# Embedded interface fonts

`Roboto-Regular.ttf` and `Roboto-Bold.ttf` are unmodified copies from the pinned Apache Flex
4.16.1 SDK used by this repository. Apache Flex identifies both files as Apache License 2.0
subcomponents. They are embedded into the source-built SWF as the deterministic interim Absolute
Control interface face; the UI does not depend on an operating-system font or an unverified
Starfield font alias.

The repository's `THIRD-PARTY-NOTICES.md` contains the corresponding attribution and license text.

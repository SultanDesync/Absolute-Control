# Credits and acknowledgements

## OSF UI

[OSF UI](https://github.com/ozooma10/osf-ui), developed by ozooma10 and its contributors,
established a shared Starfield mod-settings and web-interface platform before Absolute Control.

Absolute Control's current shared-host concept and presentation substantially overlap OSF UI's
earlier PauseMenu entry, installed-mod rail, per-mod page navigation, typed setting controls,
keybinding workflow, health/diagnostics surface, and Starfield-adjacent dark/cyan visual language.
We acknowledge that influence and do not claim the current interaction design as an independent
invention.

No OSF UI product source file is vendored in this repository as of the audit recorded in
`docs/OSF-UI-COMPATIBILITY.md`. Both projects are GPL-3.0, but any future code-level reuse must
preserve OSF UI's copyright notices, license, and additional exceptions as applicable.

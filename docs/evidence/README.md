# Research evidence records

> **Status:** Current publication/privacy policy. Runtime results are summarized in
> [`TEST-MATRIX.md`](../TEST-MATRIX.md); raw local evidence remains ignored.

Create one Markdown record per experiment using an ISO date and gate name, for example:

```text
2026-08-12-r1-minimal-movie.md
```

Every record includes:

- objective and hypothesis;
- commit and dirty/clean status;
- Starfield, SFSE, Address Library, and CommonLibSF versions;
- build mode and deployed-file hashes;
- exact setup and reproduction steps;
- expected and observed behavior;
- attached log/screenshot/video paths or links;
- result: pass, fail, or inconclusive;
- newly discovered uncertainty; and
- next experiment.

Raw proprietary game assets must not be committed. Prefer short derived notes, hashes, symbol
names, addresses tied to an explicit runtime, and user-captured evidence that is safe to publish.
